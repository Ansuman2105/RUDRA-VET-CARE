PLACE THE DOCTOR'S PHOTO HERE
=============================

1. Save your friend's photo in THIS folder.
2. Name it exactly:  rudra.jpg

   (It must be named "rudra.jpg" — lowercase — so the website picks it up.)

Tips:
- A square-ish portrait works best (e.g. 700 x 800 px).
- .jpg is expected. If you only have a .png, either rename the file
  to rudra.jpg OR change the filename in index.html (line with
  src="images/rudra.jpg").

Until you add the photo, the site automatically shows a friendly
placeholder image, so nothing looks broken.
