## 🚀 Deploy to GitHub Pages
1. Create a new repository on GitHub (e.g. `rudra-vet-care`).
2. Upload all these files (keep the folder structure — `index.html` at the root).
3. Go to **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **Deploy from a branch**.
5. Select branch **`main`** and folder **`/ (root)`**, then **Save**.
6. Wait ~1 minute — your site goes live at:
   `https://<your-username>.github.io/rudra-vet-care/`

Just double-click `index.html` to open it in any browser.
